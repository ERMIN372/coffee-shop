# Зерно — кофейня с заказом навынос (демо)

Демо-сайт для портфолио: витрина выдуманной кофейни «Зерно», меню с опциями, корзина,
оформление заказа и панель бариста. Бэкенда нет — все данные фейковые и лежат в
`src/data/mock.ts`, заказы, корзина и «сессия» админа хранятся в `localStorage`.

**Стек:** Vite · React · TypeScript · Tailwind CSS 4 · react-router-dom (HashRouter) · lucide-react.
Картинок по ссылкам нет: только CSS-градиенты, SVG-иллюстрации, иконки и эмодзи.
Шрифты (Playfair Display, Manrope) подключены локально через `@fontsource`.

## Запуск

Нужен Node.js 20.19+ (или 22+).

```bash
npm install        # установить зависимости
npm run dev        # дев-сервер: http://localhost:5173/coffee-shop/
npm run build      # проверка типов + production-сборка в dist/
npm run preview    # посмотреть сборку: http://localhost:4173/coffee-shop/
```

## Деплой на GitHub Pages

1. В `vite.config.ts` указан `base: '/coffee-shop/'` — он должен совпадать с именем репозитория.
   Если переименуете репозиторий, поменяйте и `base`.
2. В репозитории на GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Запушьте в `main` — workflow `.github/workflows/deploy.yml` соберёт проект и выложит `dist/`
   (можно запустить и вручную: **Actions → Deploy to GitHub Pages → Run workflow**).
4. Сайт будет доступен по адресу https://ERMIN372.github.io/coffee-shop/

Роутинг через `HashRouter` (адреса вида `/#/menu`), поэтому обновление страницы на
GitHub Pages не даёт 404.

## Страницы

| Страница | Адрес |
| --- | --- |
| Главная | `/#/` |
| Меню (вкладки) | `/#/menu`, `/#/menu?cat=tea`, `?cat=desserts`, `?cat=breakfast` |
| Корзина (панель справа) | кнопка в шапке или `/#/menu?cart=open` |
| Оформление заказа | `/#/checkout` |
| Экран успеха | `/#/order/<номер>` — открывается после оформления |
| Панель бариста | `/#/admin` |

## Демо-данные

- Промокод **ZERNO10** — скидка 10%.
- Вход в админку: **barista / zerno2026** (поля уже заполнены).
- В админке 16 демо-заказов «за сегодня»; кнопка «Сбросить демо» пересоздаёт их.
- Заказ, оформленный на сайте, сразу появляется в админке (в том числе в соседней вкладке).
  Через 15 секунд он сам переходит в «Готовится», а когда таймер дойдёт до нуля — в «Готов».
- На пустой странице оформления есть кнопка «Заполнить демо-заказом».

## Структура

```
src/
  data/mock.ts        все фейковые данные: меню, кофейни, отзывы, демо-заказы, промокоды
  store/              корзина, заказы, авторизация (React context + localStorage)
  lib/                форматирование, расчёт цен, слоты времени готовности
  components/         шапка, футер, корзина, модалка опций, SVG-иллюстрации
  pages/              Home, Menu, Checkout, OrderSuccess, Admin
```

Все названия, адреса и имена выдуманы. Демо-проект.
